# Antigen — marketing site

A self-contained static site for **Antigen**, a prompt-injection immune system for the DataHub metadata graph. It holds two deliverables — `index.html`, a conversion-oriented landing page, and `pitch.html`, a single-file 10-slide hackathon pitch deck (arrow-key nav, `P` presenter mode, `C` contrast check, `Esc` overview, print-to-PDF via `Ctrl/Cmd+P`) — both grounded entirely in Antigen's real facts and built on the exact brand palette (antibody green `#2EE59D`, biohazard amber `#FFB020`, lab-black `#04100B`). Everything is local: no frameworks, no build step, no external network requests, so both files work by opening them directly in a browser or by hosting the folder as-is on **GitHub Pages** (or Vercel). To preview locally, run `python3 -m http.server` from this `web/` directory and open <http://localhost:8000/> (landing) and <http://localhost:8000/pitch.html> (deck). Assets in `public/` are copies, so the folder is fully portable.
